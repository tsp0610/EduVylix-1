# Eduvylix submissions

This folder contains coding questions and submission attempts saved from SkillHub. Everything here is in a public GitHub repository and can be viewed by anyone.

## Folders

- **Courses** — course questions and their submission attempts.
- **Practice** — practice questions and their submission attempts.
- **Contest** — contest questions and their submission attempts.

Each folder is organized by submission date and question:

`<Category>/<YYYY-MM-DD>/<Question>/`

- `question.md` contains the question and relevant context.
- `Submission N.md` contains attempt N, including its source code, result, language, and submission time.

SkillHub creates these files when submissions are saved to GitHub.
